# Jackson Konur – Personal Website

This is my personal website for the Vibe Coding project. I built it with AI coding agents in Antigravity IDE and hosted it on GitHub Pages. The website includes a single-page home (profile, skills, experience, contact), a resume page, and a project page about my aerial photography.

**Live site:** https://jkonur.github.io/Natural_Intelligence-ISDS/

## Reflection

I've made websites before with Claude Design and AI agents (Numen Website linked on my personal site), but while making this one, it recommended making the resume printable so people wouldn't need to print the dark backgrounds on that page. It added a big block to styles.css wrapped in @media print, but nothing changed on the site when I refreshed it. I thought it was going to add a print button or something so when nothing changed I asked what media print did. It explained that it was a set of rules that only applies when someone does cmd p or tries to save it as a PDF. It turns the dark background into a plain black on white. I also didn't know why it was CSS and not in the HTML, and learned that since every page links to the style, changing it there would update all pages instead of copying the print rules to every page. It was also cool to see how different models handled building and editing the website, and how long it took them to make those changes.
